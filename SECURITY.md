# Security and privacy policy

This repository contains sanitized research evidence, not an operational deployment package.

Do not open a public issue containing a credential, private endpoint, raw experiment export, ballot material, identity record, packet capture, or suspected vulnerability. Use a GitHub private security advisory after the repository is created.

The package intentionally excludes implementation details that would expose authentication internals, infrastructure credentials, identity data, private ballot records, or key custody. The source excerpts show only the timing and byte-count mechanisms required to interpret the measurements.

Public Solana devnet transaction signatures are evidence identifiers, not signing credentials.
